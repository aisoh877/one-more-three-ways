# Two-minute English judging-video script

The recorded version is included at ../demo/recorded-replay-demo.mp4 . It uses English captions rather than microphone narration. This script remains a reference; actual edits are disclosed in the video documentation. Use `npm run replay` and `http://127.0.0.1:4176`. Record only the app; exclude terminals, account pages, credentials and signed URLs. Target 2:00–2:20 including deliberate pauses. Verify final contest video requirements before upload.

**0:00–0:25 — Purpose and recording disclosure**

“One More, Three Ways asks: does one more top work with the clothes I already own? This is a saved replay of three real YouCam Clothes V3 results from November second. No new generation happens in this walkthrough. The people and garment inputs are synthetic, and the prices are invented.”

[Show the replay badge and disclosure; scroll to the three wardrobe inputs.]

**0:25–0:55 — Actual API workflow and comparison**

“In our authorized trial, we uploaded three wardrobe images and one Ivory shirt reference through YouCam's File API. Clothes V3 performed upper-body replacement, and all three requests completed. The results were saved locally. Here is the reference shirt. I can compare each generated image with its original outfit.”

[Show the reference; toggle original/result on each card. Do not simulate a Generate click.]

**0:55–1:20 — Visible limitations**

“The jeans, trousers, skirt and shoes appear retained on visual inspection. But sleeves, collar, hem and buttons can differ from the reference. The neckline details in this third result need closer review. This is a styling visualization, not a guarantee of product accuracy or physical fit. Human quality approval for a larger trial remains pending.”

[Pause on the skirt result and reference without enlarging or overstating a defect.]

**1:20–1:50 — Human decision and budget**

“I approve two combinations. The forty-eight-dollar demo shirt qualifies, with a twenty-four-dollar comparison score. Approving all three changes it to sixteen dollars. This is price divided by approved combinations, not cost per wear. Below forty-eight dollars, the shirt is excluded. Buying nothing is valid.”

[Approve two, then three; budget 47, then restore 80.]

**1:50–2:15 — Recovery and close**

“Reloading preserves my choices and reuses the same saved results. The replay reads no API credential and spends no new units. The original trial was estimated at six units; actual billing remains unverified. Our separate live integration keeps receipts and does not automatically resubmit uncertain requests. The next decision stays with the shopper.”

[Reload, show retained approvals and recorded receipts. End on shortlist.]

Do not claim that replay response speed measures provider performance, that nine real comparisons exist, or that a preference checkbox certifies image quality. Any separate real-time API recording or additional generation requires its own authorization.
